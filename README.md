# Футбольна таблиця

Програма на Python для роботи зі словником. Ключ - назва команди, значення - бали.

Що вміє:
- показати всі команди
- додати і видалити команду
- показати команди по алфавіту
- знайти місце забутої команди і команди, в яких менше балів

Що треба доробити:
1. перевірка що забута команда не перша і не остання
2. щоб не можна було ввести однакові бали або таку саму назву
3. вивід команд по балах

Кожен робить свою гілку, виконує одне завдання і кидає pull request.
